1. 节点图谱（Graph View）

默认的二维画布视图。每张卡片是一个可拖拽的节点，关系是有向连线。支持：

  • 力导向布局：节点会按关系密度自动聚拢，相关越紧密越靠近。
  • 按类型着色：人物、组织、概念、事件、文件各有独立色板，一眼分辨。
  • 聚焦模式：选中某节点后，仅高亮其直接邻居，隐藏其余，便于深入阅读局部子网。
  • 筛选：按类型、标签、建立时间过滤当前可见节点。

2. 知识星云 3D 视图（Cosmos View）

切换到一个可自由飞行的三维星空。节点化作发光星体，关系是星间的流光。本视图依赖随包分发的星图视觉资源包（星云背景、法线贴图、光晕精灵、类型图标），全部离线内置，无需下载。

资源用途离线状态
星云背景 4096²3D 场景的深空氛围底图内置
细节法线贴图 4096²星体表面的凹凸光照（PBR）内置
节点光晕精灵星体发光晕圈内置
节点类型图标不同突触类型的辨识图标内置
这些资源是本应用的视觉资产，与你的知识内容无关；即使删除它们，你的数据也不受影响，只是 3D 视图的观感会变朴素。

3. 离线字体族

为保证导出的文档、卡片标题与代码块在任何机器上都呈现一致的中文与手写风格，安装包内置了一套 OFL 开源授权的字体族，全部随包离线分发：

  • Noto Sans SC / Noto Serif SC（可变字体）：正文与标题的中英混排基准字体。
  • 六款中文展示 / 手写体（马善政楷书、站酷快乐体、站酷庆科黄油体、柳建毛草、龙藏、志莽行书）：用于卡片标题、批注与强调，营造「手写笔记」质感。
授权说明：上述字体均采用 SIL 开放字体许可（OFL），可自由分发与嵌入。本应用仅以「显示用途」调用，未修改字库本体。

4. 导入与导出

操作格式说明
导入Markdown / JSON / CSV将既有笔记批量转为节点；表头映射为字段，行内链接转为关系。
导出Markdown / JSON把当前子网或全库导出为纯文本，便于迁移或留档。
快照目录副本对整个 NeoCosmosVault 做时间点复制，等同离线备份。

5. 本地优先与隐私

本应用没有云端、没有账号、没有遥测。所有索引、缓存与渲染都在本机完成。你可在系统层面彻底禁止其网络访问，功能不受影响。
