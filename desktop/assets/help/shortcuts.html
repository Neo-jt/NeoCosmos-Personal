③ 快捷键与效率

让双手留在键盘上，让星空随指尖生长
首页 新手引导 功能详解 快捷键 常见问题

全局快捷键

操作快捷键说明
新建节点N在画布中心创建一张空白卡片并进入编辑。
全局搜索Ctrl+K唤起命令面板 / 即时检索。
保存快照Ctrl+S触发一次本地仓库时间点快照（数据实时已存，此为显式备份）。
切换 3D 星云视图V在二维图谱与三维星空之间切换。
聚焦选中节点F仅高亮当前节点的直接邻居。
适配视图0（零）缩放并平移，使全部节点落入视野。

图谱导航

操作快捷键说明
平移画布按住空格拖拽 / 中键拖拽移动视口而不移动节点。
缩放Ctrl+滚轮以光标为中心缩放。
选中下一个邻居Tab沿关系跳到相邻节点。
删除节点 / 关系Delete移除选中对象（关系先删，节点连带其连线）。

3D 星云视图飞行

操作输入说明
旋转视角左键拖拽环绕星空旋转。
推进 / 后退W / S沿视线方向飞行。
横移A / D左右平移。
升降Q / E上下移动视角。
效率心法：养成「N 新建 → 拖拽连线 → Ctrl+K 检索」的循环，比任何分类文件夹都更快。关系是结构，搜索是入口，二者配合即可放弃「放在哪个文件夹」的焦虑。
