历史版本更新（v10.18.8 · 命令面板点击 / 知识产权展示 / 沉淀通道记录清理）
------------------------------------------------------------
【命令面板点击修复】顶部检索框（Ctrl K）此前结果列得出来却点不动、不跳转到卡片。
  根因是结果项落在自定义标题栏拖拽区内，动态节点未显式声明 no-drag，点击被窗口拖拽吞掉；
  旧实现也只有 Enter 键真正绑定了打开动作。本版结果项改为真正的按钮，内联样式用
  CSSStyleDeclaration 认可的 camelCase 写入 no-drag，样式与 v7 视觉层双重保险；
  同时绑定 pointerdown 与 click 双通道并防重复执行，点击即打开对应卡片并切到文档台。

【知识产权展示撤下】设置页「完整能力矩阵 / 查看能力中枢」入口、功能项目里的中枢卡片、
  命令面板的中枢直达命令全部撤下；能力中枢视图与路由仅为内部自检保留，不再对用户展示。

【沉淀通道记录清理】「恢复 N 项移除」按钮显示的是本机过去点过「移除接入」留下的墓碑，
  不是程序开发残留。本版已清理本机 13 条历史墓碑（原策略文件已在本机备份），
  并把按钮改为来源明确的「撤销 N 条移除记录」，确认框与脚注如实说明来源；无记录时不再显示。

历史版本更新（v10.18.7 · 跨库检索 / 启用库对外管控 / 品牌统一 / 总览重设计）
------------------------------------------------------------
【跨库检索修复】左栏卡片检索在「启用的库 / 全部库」范围此前完全忽略搜索框输入，
  输入关键字毫无反应；本版把本库与跨库检索统一到同一套匹配（文本 / 路径 / 拼音首字母 / 标签），
  跨库过滤时自动展开命中库与目录、显示真实命中数、无命中给一键清除出口。

【启用库对外管控（核心）】此前 WorkBuddy / AutoClaw / OpenClaw 经 MCP 调取时从不读取
  「启用 / 停用」状态，用户停用的库照样能被外部 AI 检索——停用形同虚设。本版：
  · 主进程把「已启用知识库白名单」发布为跨进程共享真源，切库 / 启停 / 冷启动都会重发布；
  · MCP 启动即校验，被停用的库进入受限模式，所有内容检索真实拒绝，仅自查工具可用；
  · 每次检索调用复查白名单，用户在客户端停用后下一次调用即时生效，无需重启连接；
  · 桌面端本地检索不受此约束；老客户端未发布白名单时兼容放行，升级期不集体断连。
  · 新增 kb_access_policy 工具，让外部 AI 自查可访问范围与权限边界，答得准确不再猜测。

【品牌统一】清除对外旧开发代号：MCP 握手声明正式产品名 NeoCosmos，默认服务名改为 neocosmos，
  skill 目录改为 skills/neocosmos，工具描述与日志前缀统一；旧名仅作兼容别名保留。
  已连接的宿主配置按本地别名工作，改名不影响既有连接。

【全库总览重设计】学习星图视觉语言：深空星系 + 库域卡片网格下钻 + 星图式 KPI 卡与图例胶囊，
  每座库用真实库色、卡片/标签/关联读数、启用态徽标，点卡即聚焦星系；关联强度改可视化条。
  全部数据来自 vault:list / vaults:xgraph 真实扫描，零示例。

【对外发布合规】LICENSES.md 资产边界改为如实说明（语料快照/词表与签名资产的真实范围）；
  desktop 包许可证改标准 SPDX；重新生成开源目录，排除签名/语料/明文口令/交付产物。

【反逆向加固】QS-Shield 完整性 SHA3 哈希链纳入本版的跨库检索、启用库白名单、总览与 MCP 内核；
  篡改这些安全边界文件即被检出并降级。诚实边界不变：Electron 的 JS 源码可被解包，
  「绝对不可逆向」不存在；个人版又是 AGPL-3.0 开源，本层只显著提高逆向与篡改成本。

【开源】个人版以 AGPL-3.0 开源；个人 / 学习 / 研究 / 内网免费，闭源商用或 SaaS 须取得商业授权。

一、产品定位
------------------------------------------------------------
NeoCosmos 是一款「关系优先」的本地优先知识网络软件。
带类型、带权重、会强化也会衰减的关系（突触）是第一公民，
笔记只是突触交汇处的投影。

全部数据留在本机，不上传任何云端；无模型、无网络调用。
本安装包为纯净客户端，不含任何内置知识库内容；
知识库由使用者自行创建或导入。随包提供离线中文排版字体
与 3D 星图 / 星空环境渲染资源，无需联网即可完整使用。

三、认知与数学内核（如实边界）
------------------------------------------------------------
· 量子形式主义模拟：以 30 个真实解剖脑区为叠加态基底、
  183 条真实轴突为耦合图，经酉式演化与 Born 规则坍缩，
  把测量到的脑区及一跳邻居按连接组 latency_ms 回灌为
  可回放的轴突脉冲。界面显示概率、熵与归一化自检。
· 认知算法：脉冲神经网络 SNN / Hopfield 吸引子联想记忆 /
  HTM 稀疏表征序列记忆 / 预测编码等确定性数值算法。
· 自主引擎（ASTRA）：确定性、可审计、可关闭、可回滚的
  本地行为架构，含内在驱动、三层记忆、自主目标、
  带数值理由链的加权决策与策略自演化。
  成熟度等级由真实使用数据（心跳、记忆、世代、目标成功率、
  反馈质量）推导，仅调整界面与行为权限。
· 深度数学内核：矩阵指数与酉演化保范数、哈密顿量、
  Grover 振幅放大、离散时间量子游走、密度矩阵 / 冯·诺依曼熵 /
  布洛赫向量、相位阻尼与振幅阻尼 Kraus 算符、香农熵 / KL 散度 /
  互信息、贝叶斯精度加权更新、变分自由能、PageRank、
  特征向量中心性、Jacobi 特征值、归一化拉普拉斯谱隙。
  21 项数值自检随包可一键运行，逐项给出实算值与所用公式。
· 自我迭代闭环：真实运行态观测 → 预测 → 误差 → 贝叶斯更新 →
  变分自由能 → 误差分布熵 → 探索/利用决策 → 退相干映射 →
  审计与落盘。结论会真实改写策略探索率与置信度，
  状态可续跑、可逐代审计；不是只把数字显示出来的装饰。

【重要】以上全部是本机 CPU 上的经典确定性符号 / 数值模拟，
非真实量子计算，不是生物神经，不具备生命或意识。
行为架构无模型、无网络、可审计、可关闭、可逐代回滚；
界面中的成长阶段与驱动名称均为状态可视化，不是能力声称。
