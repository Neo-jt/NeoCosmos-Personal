# NeoCosmos 概念构想：关系优先的突触式记忆体

> 规格先行。本文定义"类脑"的可验证落点，先于任何代码。

## 1. 一句话定义

NeoCosmos 不是一个"更好的笔记软件"。它是一个**以关系为第一公民的本地优先记忆体**：把用户磁盘上的真实文件夹当作唯一真相源，把里面的条目自动织成一张**带类型、带权重、会被强化、会衰减、能联想扩散**的突触网络；它同时是一个 **MCP Server**，可被 WorkBuddy / AutoClaw 等外部 AI Agent 当作"长期记忆后端"调用，并且**每次问答后把结论回写沉淀进网络**——用得越多，网络越厚。

## 2. 结构倒置：从"节点中心"到"关系中心"

多数知识工具的结构前提是：**文档 / 卡片是主实体，链接是从属于节点的引用**。这决定了它们的能力上限：边只能由人主动写、所有链接彼此等价且恒定、图谱是给人看的装饰。

NeoCosmos 把前提倒置：

> **突触（关系边）是第一公民。节点只是突触交汇处的暂态投影。**

由此带来的四个架构级差异（无法作为插件外挂，必须内建于索引与检索层）：

| 维度 | 节点中心工具的结构性上限 | NeoCosmos 的关系中心架构 |
|---|---|---|
| 关系从哪来 | 边只能人主动写，不写就不存在 | 边自动生长（语义/共现/时间/因果多通道），人写的仅是权重最高的一类 |
| 边的性质 | 所有链接等价、恒定、无来源无理由 | 7 类边 + 动态权重（用则强化、久不用则弱化，`floor=0.05` 只弱化不删记忆） |
| 检索方式 | 精确匹配 + 人点击跳转；召回是"一堆命中项" | 激活扩散召回，且返回**联想路径**（因 A→B→C 故给 C），结果自带推理链 |
| 谁在用它 | 面向人 | 面向人 + 面向 AI Agent；读写有权限分级与审计 |
| 用完之后 | 问答一次性消费，知识量不变 | 回写闭环，第二次问同一问题成本趋零 |

## 3. 四类独有机制（"类脑"的可验证定义）

1. **突触分级（Synaptic Typing）**：7 类带类型、带基础权重、带半衰期的边。
2. **突触可塑性（Plasticity）**：Hebbian 启发——"同时激活的突触一起强化"。边权重随使用动态变化。
3. **激活扩散（Activation Diffusion）**：检索是"从命中点向外联想"，不是全库扫描；输出带可解释推理链。
4. **巩固与优雅遗忘（Consolidation & Graceful Forgetting）**：空闲时"睡眠"任务做消歧、补边、矛盾检测、衰减；遗忘是软删（进 `_graveyard/`）+ 硬删两级，被遗忘的边同步清理、永不再召回。

## 4. 真实边界（不夸大、不贬损）

- 不训练模型、不内置抓取、不做通用 Agent 运行时——只做 Agent 的**记忆后端**。
- 兼容用户既有 Markdown（读合法），但**不复用任何竞品的专有表达**（界面 / 格式 / 名称 / 运行时）。
- 断网、无模型 API 时，全文检索、图谱、双链、沉淀回写必须全可用（语义检索降级为 BM25）。
