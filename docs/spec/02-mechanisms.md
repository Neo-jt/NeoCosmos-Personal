# NeoCosmos 机制规格（7 项，逐个实现不许省略）

## M1 突触分级（7 类边）

| 边类型 | 含义 | 来源 | 基础权重 | 衰减半衰期 |
|---|---|---|---|---|
| `explicit_link` | 手写 `[[双链]]` / UI 手动建边 | 人 | 1.00 | 不衰减 |
| `causal` | A 导致/解释/支撑 B | 人或模型标注 | 0.90 | 180 天 |
| `hierarchical` | 父子/包含/属于某领域 | 目录/MOC | 0.80 | 365 天 |
| `question_answer` | 问答卡片 ↔ 证据条目 | 回写流程 | 0.85 | 90 天 |
| `semantic_similar` | 向量余弦 > 阈值 | embedding | 0.30~0.70 | 30 天 |
| `co_occurrence` | 同段/同次检索共现 | 统计 | 0.20~0.50 | 21 天 |
| `temporal` | 同一时间窗产生 | 时间戳 | 0.25 | 14 天 |

图谱 UI 必须可按边类型开关与过滤；检索按类型加权；不同类型走不同衰减曲线。

## M2 突触可塑性（LTP/LTD）

```
w(t) = clamp( w_base · Π(1 + α·Δ强化) · exp(-λ·Δt), floor, cap )
λ = ln2 / 半衰期(边类型)
默认：α = 0.15，floor = 0.05（永不归零，只弱化不删记忆），cap = 3.0
```

- 强化事件：被检索路径实际使用 / 被点开 / 被问答引用 / 用户确认。
- 弱化事件：用户否定关联 / 答案被纠错 / 检索结果被判无关。

## M3 激活扩散检索（联想而非查字典）

```
1) 种子召回：向量 top-K ∪ BM25 top-K ∪ 标签/目录精确匹配
2) 扩散：A(v) = Σ_u A(u) · sim(u,v) · w(u,v) · β^d
         β = 0.6（阻尼），最大 3 跳，激活阈值 0.08，剪自环
3) 融合：RRF  score(d) = Σ_lists 1/(k + rank), k = 60
4) 输出带 activation_path（A→B→C 的推理链）+ 置信度
```

联想路径返回给调用方，并可在图谱高亮——这是可解释性的核心，也是与"朴素向量 RAG"的分水岭。

## M4 三层记忆分区

| 层 | 存什么 | 目录 | 检索优先级 |
|---|---|---|---|
| 工作记忆 | 当前上下文/临时剪藏/待整理 | `_inbox/` | 最新优先，7 天后降级或提醒 |
| 情景记忆 | 带时间戳的原始记录（问答/决策/会议/daily） | `_memory/episodic/` | 时间邻近加权 |
| 语义记忆 | 抽象出的概念/实体/结论卡 | `_memory/semantic/` | 精确匹配优先，权重最高 |

情景层同一概念多次出现 → 巩固任务提炼为语义层卡片（草稿待确认，不自动覆盖）。

## M5 记忆巩固（"睡眠"任务）

空闲/定时触发：① 实体抽取与消歧 ② 补建语义/共现边、更新权重 ③ 近似概念合并**建议**（>0.92 只建议不自动合并）④ 孤立节点检测入待整理队列 ⑤ 矛盾检测（同概念下互斥陈述）⑥ MOC 自动更新 ⑦ 权重衰减批量落库。进度可见、可暂停、可一键回滚所有机器生成的边。

## M6 反思（健康度）

输出：节点数、边数、平均度、孤儿率、边老化分布、Top 高频访问、长期零访问。每轮巩固产出一份报告。

## M7 可遗忘（隐私可控）

- 软删：索引移除 + 文件移入 `_graveyard/`；
- 硬删：连文件删除，需二次确认；
- 被遗忘条目的边必须同步清理，后续检索不得再召回。
