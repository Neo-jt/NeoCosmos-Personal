# 原创性与知识产权红线声明（NeoCosmos 净室基线）

> 本文件是产品最高优先级约束的书面基线，公开说明本项目的原创性原则与合规红线。

## 一、本产品的创新原点（从理念开始就不同）

现有本地知识工具（无论哪一款）的结构前提是**节点中心**：一篇文档 / 一张卡片是主实体，链接是附属于节点的"引用"。NeoCosmos 的结构前提是**关系中心**——

> **第一条公民是"突触"（带类型、带权重、会强化、会衰减、可解释的关系边），节点只是突触交汇处的暂态投影。**

这一倒置带来四类只能靠架构实现、无法作为插件外挂的能力：

1. **关系自动生长**：边来自语义 / 共现 / 时间 / 因果多通道，人写的 `[[链接]]` 只是权重最高的一类边，而非唯一来源。
2. **突触可塑性**：边权重随"被使用"强化、随"被冷落"衰减（`floor=0.05`，永不归零——只弱化不删除记忆）。
3. **激活扩散召回**：检索不是"查字典返回一堆命中项"，而是"从命中点向外联想"，且返回**推理链**（因 A→B→C 故推荐 C）。
4. **回写闭环 + 巩固**：每次问答沉淀成卡片并入网；空闲时"睡眠"任务做消歧、补边、矛盾检测、衰减——网络越用越厚、越睡越准。

## 二、绝对禁止（法律与道德双重红线）

| 编号 | 禁止事项 |
|---|---|
| N1 | 复制 / 改写 / 洗稿任何竞品专有源代码 |
| N2 | 反编译、逆向其二进制 / 打包产物 / 私有格式以推导实现 |
| N3 | 照搬其私有数据结构、内部 API、私有配置文件名与键 |
| N4 | 使用其名称、logo、图标、官方截图、官方文案、宣传语 |
| N5 | 复刻其界面布局 / 配色 / 图标集 / 交互组合（"看起来像它"） |
| N6 | 变体拼写或近似命名蹭品牌，或"同款 / 平替"式表述 |
| N7 | 做成其插件、进其插件市场、依赖其专有运行时实现核心机制 |
| N8 | 生成与其私有 API 同签名同语义的函数 / 类 / 模块名 |

## 三、明确允许（避免"因怕抄袭而自废兼容性"）

- 读取用户自己的 `.md` 文件（Markdown / CommonMark 为开放规范，`.md` 为公共格式）。
- 解析社区通用语法（`[[双链]]`、YAML frontmatter、`#标签`、附件相对路径）——多款工具共用的行业约定，非某家独占；本产品**按公开约定自行实现**。
- 输出纯 CommonMark，不加入"离开本产品就打不开"的私有加密格式。
- 思想层面启发合法（本地纯文本 + 链接 + 图谱这一概念早于任何单一产品）；非法的是**表达的复制**。

## 四、自研表达清单（本产品逐项独立设计）

- **视觉语言**：独立 Design Token（色板 `ink / pulse / synapse / dormant` 等自拟命名），图标与组件形态自研。
- **信息架构**：以"知识网络 / 问答 / 沉淀队列 / 调用审计 / 记忆巩固"为一级入口，文件树降为可选视图。
- **术语体系**：激活扩散、突触、巩固、沉淀区、记忆分层（工作/情景/语义）、待整理队列、审计——均为本项目术语。
- **格式命名空间**：专属字段一律 `neokb_*` 前缀，元数据目录 `.neokb/`；`node_id` 算法、边类型枚举、权重公式均自研定义。

## 五、本仓库已落实的净室证据

- 零第三方运行时依赖（见 `LICENSES.md`）。
- 核心模块命名：`KbStore` / `KbEdge` / `ActivationEngine` / `ConsolidationScheduler` / `SafeResolver` —— 均为自研抽象，无竞品私有 API 同签名。
- 规格先行：`docs/spec/` 先于代码成稿。
- 发布前将跑 `test/run-all.js` 与 `offline-eval/run.js`，输出工程 + 超越性 + 原创性三类证据。

**一句话**：能超越的，是我们的架构（关系优先 + 权重动力学 + 可解释联想 + 回写闭环 + 巩固），不是任何产品的代码、名字、界面。兼容用户数据正当，复制表达禁止。
